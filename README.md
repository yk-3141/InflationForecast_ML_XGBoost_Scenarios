# InflationForecast_ML_XGBoost_Scenarios

# CPI Forecast under Policy Rate Scenarios
日本の金融政策と物価の関係を機械学習で予測するプロジェクト

---

## 📌 プロジェクト概要 (Project Overview)
本プロジェクトでは、日本銀行の政策金利と総務省統計局のCPIデータを用いて、
XGBoostモデルによる物価予測を実施しました。
複数シナリオ（現状維持・引き上げ・引き下げ）を設定し、95%信頼区間を可視化することで、
金融政策の変化が物価に与える影響を定量的に評価します。

---

## 🎯 目的 (Objective)
- 金融政策と物価の関係をデータサイエンスで検証
- シナリオ分析による政策決定支援の可能性を示す
- 機械学習モデルの構築・評価・可視化スキルをアピール

---

## 📂 使用データ (Data)
- **政策金利**：日本銀行統計データ（44年分）
- **CPI**：総務省統計局データ（月次）
- **特徴量**：
  - 金利ラグ（1,3,6,12ヶ月）
  - 移動平均（3ヶ月）
  - 変化率（前月比）

---

## 🛠 技術スタック (Tech Stack)
- **Python**: pandas, numpy, matplotlib, seaborn
- **モデル**: XGBoost
- **ハイパーパラメータ最適化**: Optuna
- **可視化**: Matplotlib + カスタムスタイル

---

## 🔍 手法 (Methodology)
1. データ取得（日本銀行API + e-Stat）
2. 前処理（欠損値処理、特徴量生成）
3. モデル構築（XGBoost）
4. ハイパーパラメータ最適化（Optuna）
5. シナリオ分析（現状維持・引き上げ・引き下げ）
6. 信頼区間の追加（±1.96 × RMSE）

---

## ✅ 結果 (Results)
- **評価指標**: RMSE = **1.69**
- **シナリオ比較**:
  - 金利引き上げ → CPI緩やかに上昇
  - 金利引き下げ → CPI横ばい傾向
- **グラフ**:
  - 複数シナリオの予測線
  - 95%信頼区間を表示
